# Artificial Neural Network (ANN) – MNIST Handwritten Digit Classification

This project demonstrates the implementation of an Artificial Neural Network (ANN) using the MNIST dataset to recognize and classify handwritten digits (0–9).

The model is trained on 60,000 training images and evaluated on 10,000 test images. It learns patterns from handwritten digit images and predicts the corresponding numerical labels.

**Key Highlights:**
- Explored and preprocessed the MNIST dataset.
- Built an Artificial Neural Network using Python.
- Trained the model to recognize handwritten digits.
- Evaluated model performance using test data.
- Predicted handwritten digits using the trained model.

**Technologies Used:**
- Python
- TensorFlow / Keras
- NumPy
- Matplotlib
- Jupyter Notebook

**Objective:** To understand the fundamentals of Artificial Neural Networks and implement a deep learning model for handwritten digit classification.
